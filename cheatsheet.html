Read left to right: minute hour day-of-month month day-of-week

🔣 Wildcard syntax

*
Any value* in a field matches every possible value
*/n
Every n units — */5 in minutes = every 5 minutes
a-b
Range — 1-5 in weekday = Mon–Fri
a,b
List — 1,15 in day = 1st and 15th of month
a-b/n
Range with step — 0-12/2 in hours = every 2h from midnight to noon
?
No specific value (Quartz / some platforms) — alias for * in day/weekday fields

⚡ Special strings (shorthand)

Supported in most cron implementations and GitHub Actions on: schedule:.

@yearly
0 0 1 1 *
Once a year, Jan 1st midnight
@annually
0 0 1 1 *
Alias for @yearly
@monthly
0 0 1 * *
Once a month, 1st at midnight
@weekly
0 0 * * 0
Once a week, Sunday midnight
@daily
0 0 * * *
Once a day at midnight
@midnight
0 0 * * *
Alias for @daily
@hourly
0 * * * *
Every hour at :00
@reboot
(system dependent)
Once at system startup (crontab only)
